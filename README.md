# 出货缺陷率质量分析（选择偏差 × 复查误判联合估计）

## 业务问题

复查资源天然偏向模型分数高的样品。若直接用复查标签计算缺陷率：

1. **选择偏差**：高分件被过度代表，低分缺陷件（盲区）系统性缺失；
2. **测量误差**：复查者本身会漏检/误判，标签不是真值；
3. **结构性盲区**：个别批次设计抽样概率为 0，没有任何复查机会；
4. **证据版本**：补录结果到达后当前估计要更新，但已锁定月报必须保持原证据。

本项目用虚构合成数据从零实现采样台账、统计估计与可解释网页，全部代码零第三方依赖
（纯 ESM，浏览器与 Node 共用同一套引擎）。

## 快速开始

```bash
node src/lib/generator.js          # 重新生成确定性合成数据（固定种子，可复现）
npm test                           # 11 项验证测试（对照隐藏真值）
node scripts/serve.mjs             # http://localhost:8731/src/web/index.html
```

## 统计方法

### 1. 采样台账（`src/lib/dataio.js`）

每件产品记录两波抽样的设计概率：

- v1 常规波次：伯努利抽样，π₁ 随模型分数升高而升高（制造选择偏差）；
- v2 补录波次：在 v1 未中选总体中做条件加权抽样（盲区逆概率优先 + 高分对照）。

累计入选概率 `P = 1 − (1−π₁)(1−π₂)`，Horvitz–Thompson 权重 `w = 1/P`。
概率恒为 0 的批次不进入估计样本，由覆盖性分析单独处理。

### 2. 两步联合纠正（`src/lib/estimator.js`，顺序不可颠倒）

```
原始标签率 ──IPW 逆概率加权（纠选择偏差）──> 表观阳性率 q
           q ──Se/Sp 误判反演（纠测量误差）──> 真实缺陷率 p
           p = (q − (1−Sp)) / (Se + Sp − 1)
```

只做第一步等于把复查标签当真值；只做第二步则高分缺陷件仍被过度代表。
页面同时输出 naive / weighted / corrected 三个口径，量化每一步纠正的贡献。

- 点估计：Hájek 比率估计；
- 区间：复查件加权 Bootstrap（400 次，固定种子）的 2.5/97.5 分位；
- 测量不确定性：Se/Sp 轮廓区间四角传播的不确定性带；
- 零概率批次：部分识别区间 `[0,1]`，与覆盖部分混合得到总体宽区间，绝不外推。

### 3. 误判识别（`src/lib/misclassification.js`）

- **Hui–Walter 潜类别 EM（MAP）**：两名复查者共同审查样本 × 6 个患病率不同的产线分组，
  无真值条件下估计 Se/Sp；625 点网格启动避免局部最优，弱 Beta(2,2) 先验压制
  "完美分类"边界伪解；
- **轮廓似然区间**：两阶段网格（粗 0.1 步长 + 细 0.03 步长），似然差 ≤3.84 的参数范围；
  无法识别时返回 `partial-identification` 并保留区间，不给单点伪装；
- **仲裁样本（gold）**：已知真值件的二项/Wilson 估计，作为主锚点；
- **3 复查者通用 EM**：经典可识别设计的正确性验证（测试用）；
- **人工假设**：界面可输入 Se/Sp 做 What-if 重算，只影响当前视图。

### 4. 抽检建议（`src/lib/recommendations.js`）

固定预算 B 比较三种策略，**每条建议绑定具体 unitId 候选清单与入选理由**：

| 策略 | 选择规则 | 本数据预期方差下降 |
|---|---|---|
| score-first | 模型分数最高（现状倾向） | ~11% |
| blind-spot | 逆概率权重 × 缺陷不确定度（盲区优先） | ~36% |
| balanced | 盲区 70% + 分数 20% + 零实现批次奖励 | ~35% |

零概率批次不会出现在任何候选清单中——没有抽样机制时追加复查无从谈起，
页面明确提示需先建立全检/新设备抽检机制。

### 5. 月报证据版本（`src/lib/reports.js`）

锁定快照记录证据截止日期、波次、记录数与 SHA-256 指纹。
v2 补录（2026-11-20 到达）只进入"当前视图"；锁定版 2026-10 月报重放时
证据截止 10-31 必然排除 v2，数值与指纹逐位不变（测试守护）。

## 页面功能

1. 总体 KPI：纠正率 + CI、naive 偏差缺口、覆盖率、含未覆盖群体的混合区间；
2. 误判模型与假设调整：EM 四格表、轮廓区间、边界伪解展示、Se/Sp What-if；
3. 产线差异：三口径分组条形图 + CI 标记 + 表格视图（无障碍替代）；
4. 逐批追溯：12 个批次的覆盖/缺口状态与部分识别区间；
5. 抽检建议：预算可调、三策略收益对比、候选清单可导出 JSON；
6. 月报版本：锁定版 vs 当前版的证据指纹与估计对照。

## 合成数据与验证

`generator.js` 固定种子生成 4,550 件出货、1,000+ 复查记录、共同审查与仲裁样本。
真值写入 `data/truth.secret.json`，**估计引擎代码路径不读取该文件**；
`tests/validate.test.js` 通过生成器返回值取得真值，检验：

- 选择偏差存在且 naive 高估、IPW 纠正后线级总绝对误差下降 ~78%；
- 零概率批次不进估计、不可外推、不进建议候选；
- 误判反演方向正确，无信息测量（Se+Sp≈1）显式返回不可识别；
- gold 与 EM 点估计恢复预设 Se/Sp；退化共识数据下降级为部分识别；
- 3 复查者大样本下 EM 可识别并恢复参数；
- 锁定月报证据指纹与数值不被补录/假设改写；
- 同 Bootstrap 种子结果逐位可复现。

## 目录结构

```
src/lib/    估计引擎（浏览器/Node 共用）
  config.js          常量与数据契约
  rng.js             确定性 PRNG、Beta/正态分布
  generator.js       合成数据 + 采样台账生成
  dataio.js          加载、累计入选概率、覆盖性分析
  misclassification.js  Hui-Walter EM / gold / 轮廓区间 / 假设覆盖
  estimator.js       IPW + 误判反演、Bootstrap、产线对比
  recommendations.js 预算策略与候选清单
  reports.js         月报快照与证据锁定
  pipeline.js        流水线编排
src/web/    网页（index.html / styles.css / charts.js / app.js）
tests/      node:test 验证（统计正确性 + DOM 桩渲染）
data/       生成的 jsonl 台账与 truth.secret.json
```
